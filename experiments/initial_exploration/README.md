# First experiments using Python + NumPy + Matplotlib

## Procedural Generation

> Content is generated by an algorithm (a procedure), usually based on mathematical functions.

We define a function, and the function computes the result automatically.

There are no explicit “if this, then that” symbolic rules — instead, the result emerges from formulas.

### Simple Example:

![Simple Procedural Example: Grayscale](/assets/experiments/initial_exploration/grayscale.png)

```py
for x in range(width):
    for y in range(height):
        value = sin(x * 0.1) * cos(y * 0.1)
        image[x, y] = value
```

This would generate a grayscale texture. Here:

- The texture is generated purely by a mathematical function
- No logical rules.
- Just computation.

### Visual example: Stripes

![Visual Procedural Example: Stripes](/assets/experiments/initial_exploration/stripes.png)

```
if sin(x * 0.2) > 0:
    color = white
else:
    color = black
```

The pattern emerges from a mathematical wave function.

## Rule-Based Generation

> Content is generated by applying explicit rules or logical decisions

Instead of computing values from formulas, we define symbolic rules. These rules describe structure, not just numbers.

### Simple Example

Rule:

- Every second tile is black
- Every third row is red

![Simple Rules-Based Example](/assets/experiments/initial_exploration/simple_rulebased.png)

```
if x % 2 == 0:
    color = black
elif y % 3 == 0:
    color = red
else:
    color = white
```

### Visual Example: L-System (Tree)

The rule looks like this:

![Visual Rules-Based Example: L-Systen (Tree)](/assets/experiments/initial_exploration/tree.png)

```
F → F[+F]F[-F]F
```

This is a rewriting rule. Each iteration replaces symbols based on rules. That is rule-basd generation.

## Core Differences

| Procedural             | Rule-Based                    |
| ---------------------- | ----------------------------- |
| Mathematical functions | Logical / symbolic rules      |
| Continuous structures  | Discrete structural decisions |
| Often numeric          | Often symbolic                |
| Example: Perlin noise  | Example: L-systems            |
| Smooth patterns        | Structured patterns           |
