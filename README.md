# Algorithmic Texture Synthesis

Bachelor Thesis Project

Lucerne University of Applied Sciences and Arts (HSLU)  
Department of Computer Science

## Overview

This repository contains the implementation and documentation of a bachelor thesis on algorithmic texture synthesis in computer graphics.

The project investigates procedural, rule-based, and optimization-based approaches for generating realistic textures such as wood, marble, and other structured materials.

The focus lies on:

- Procedural texture generation
- Rule-based texture modeling
- Parameterized texture systems
- Optimization-driven parameter estimation
- Quantitative evaluation using defined similarity metrics

## Motivation

In computer graphics, texture mapping is commonly based on pre-existing image data.
However, algorithmic texture synthesis enables:

- Infinite resolution
- Parameter control
- Compact representation
- Adaptability
- Procedural variation

This project explores hybrid approaches combining procedural methods with rule-based systems and optimization techniques.

## Features

- Implementation of procedural noise-based textures
- Rule-based pattern generation
- Parameter tuning framework
- Optimization-based parameter fitting
- Texture similarity metrics
- Experimental evaluation
