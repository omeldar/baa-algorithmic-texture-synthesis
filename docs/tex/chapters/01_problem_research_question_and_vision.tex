\section{Problem}

In computer graphics, realistic and varied surface appearance is an important part of visual quality. A common approach for representing surface detail is texture mapping, where pre-existing image textures are applied to geometric surfaces. This allows materials such as wood, stone, soil, fabric, or metal to be represented without modelling every small surface detail geometrically.

However, traditional image-based textures also introduce several limitations, especially in dynamic or procedurally generated environments. Image textures are usually fixed assets. They have a predefined resolution, limited variation, and often need to be repeated across larger surfaces. This can lead to visible tiling artifacts and increases the amount of texture data required for large virtual worlds. In addition, static textures are only indirectly controllable. Changing their appearance usually requires manual editing or the creation of additional texture variants.

Algorithmic texture synthesis provides an alternative approach. Instead of relying only on stored image assets, textures are generated by computational methods. Procedural methods use mathematical functions such as noise, fractals, or domain transformations to create texture patterns. Rule-based methods describe texture structures through explicit rules, for example for repeated, cellular, or crack-like patterns. Optimization-based methods can be used to estimate parameters of such texture models in order to approximate a given target texture.

A central challenge is that algorithmically generated textures usually cannot reproduce a concrete real-world texture exactly. Procedural and rule-based models often describe a class of visual patterns rather than a specific image sample. Therefore, the goal is not exact reproduction, but controlled approximation. This means that model parameters are adjusted so that the generated texture becomes visually or statistically closer to a target texture according to a defined metric.

This thesis investigates how procedural and rule-based texture synthesis methods can be implemented and evaluated in the context of a procedural real-time environment. In addition, optimization-based approximation is investigated as a parameter estimation layer for selected procedural texture models. The work focuses on controllability, variation, reproducibility, runtime behaviour, and the practical suitability of these methods for typical computer graphics use cases. This corresponds to the assignment goal of researching existing systems, defining a suitable use case, implementing procedural, rule-based, and optimization-based parameter estimation methods, and evaluating the results with respect to quality, flexibility, reproducibility, controllability, and suitability for computer graphics applications.

To investigate these aspects, a custom research prototype is developed. The prototype provides a controlled environment for generating parameterizable textures, applying them to a simplified procedural real-time scene, and comparing their behaviour under reproducible conditions. It is not intended as a production-ready material authoring tool, but as an experimental system for studying the strengths and limitations of different algorithmic texture synthesis approaches.

\section{Research Questions}

Based on the problem described above, this thesis aims to investigate several research questions related to the generation and approximation of textures through algorithmic methods.

The main research question can be formulated as follows:

\textit{How can algorithmic texture synthesis methods be applied in procedural real-time environments to improve variation, controllability, and scalability of generated textures?}

To address this main question, several sub-questions can be defined:

\begin{enumerate}
    \item What existing approaches and systems for algorithmic texture synthesis are described in current research and industry applications?
    \item How can procedural and rule-based texture synthesis methods be implemented within a procedural real-time environment?
    \item To what extent can procedural parameters be optimized in order to approximate target textures?
    \item How do different texture synthesis approaches compare with respect to visual quality, runtime performance, reproducibility, and parameter controllability?
\end{enumerate}

These research questions guide the theoretical investigation, the design of the prototype, the implementation of the texture synthesis methods, and the later evaluation. They also define the boundary of the work: procedural and rule-based methods form the main implemented texture generation approaches, while optimization is used to investigate how selected procedural parameters can be estimated to approximate target textures.

\section{Vision}

The vision of this thesis is to demonstrate how algorithmic texture synthesis can support more flexible and scalable texture workflows in computer graphics. Instead of treating textures only as static image resources, the work explores how textures can be generated, modified, and evaluated through parameters and rules.

This is especially relevant for procedural real-time environments, where large amounts of visual content may be needed while memory usage, runtime performance, and variation remain important. In such environments, algorithmic methods can reduce the dependency on large texture libraries and allow visual variation to be created dynamically. Parameters such as scale, color, structure, seed values, or pattern density can be adjusted to generate different texture variants from the same underlying model.

The thesis therefore aims to provide both a conceptual and practical contribution. Conceptually, it compares procedural, rule-based, and optimization-based approaches with respect to their role in texture generation and approximation. Practically, it implements a prototype that allows these approaches to be tested under controlled and reproducible conditions. The prototype serves as a research instrument for observing how different texture models behave, how controllable their parameters are, how suitable they are for real-time use, and how well selected models can be adjusted toward target textures.

The expected outcome is not a universal texture synthesis system that can reproduce any input texture perfectly. Instead, the goal is to understand where algorithmic texture synthesis is useful, where its limitations are, and how procedural, rule-based, and optimization-supported methods can contribute to practical computer graphics workflows. This makes the work relevant for areas such as procedural content generation, real-time rendering, game development, simulation, and educational experimentation with texture synthesis methods.
